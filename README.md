# Avatar Customizer

A browser-based Minecraft skin editor. Paint pixels, mix and match parts, preview the
skin on a 3D model, and export a 64×64 PNG you can upload to Minecraft.

## Getting started

```bash
npm install
npm run dev        # start the dev server
npm test           # run unit tests
npm run build      # type-check and build to dist/
```

## Project layout

| Folder | What goes there |
| --- | --- |
| `src/core/` | Skin model, UV map, layers, undo history. No DOM code, so it's easy to unit test. |
| `src/editor/` | 2D pixel editor canvas and painting tools (pencil, eraser, fill, eyedropper, mirror). |
| `src/preview/` | 3D preview using [skinview3d](https://github.com/bs-community/skinview3d). |
| `src/customizer/` | Part catalog (hair, shirts…) and applying parts as layers. |
| `src/io/` | PNG export, PNG import (including legacy 64×32 skins), localStorage autosave. |
| `src/ui/` | Panels: toolbar, color picker, layers, parts, model toggle. |
| `src/data/parts.json` | Part catalog, generated by `scripts/generate-parts.mjs`. |
| `public/assets/parts/` | Part textures: full 64×64 transparent PNGs that only paint their own region. |
| `tests/` | Vitest unit tests. |

## Adding parts

Each part is a 64×64 transparent PNG laid out like a normal skin, with only its own
pixels filled in. Recolorable parts should be drawn in light gray; the app multiplies
them by the chosen color.

- Hand-drawn part: put the PNG in `public/assets/parts/<category>/` and add an entry to
  `src/data/parts.json`.
- Generated part: add it to `scripts/generate-parts.mjs` and run `npm run generate:parts`.
  This overwrites `parts.json`.

Parts are drawn for the classic (4px arm) model.
